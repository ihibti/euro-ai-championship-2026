# Brief: Towards Unbounded Machine Unlearning (SCRUB)

Kurmanji, Triantafillou, Hayes, Triantafillou. arXiv [2302.09880v3](https://arxiv.org/abs/2302.09880) (NeurIPS 2023).
PDF: `papers/2302.09880v3_scrub-unbounded-unlearning.pdf` (fetch with `make papers`).

This paper is one of three organizer references. It is **not** assumed to define the challenge.
Sections 1–5 report the authors' work, with section/table references. Section 6b and section 9 are our own assessment and ideas.

## 1. Problem

We start from a model w^o trained on D, a forget set D_f ⊂ D and a retain set D_r = D \ D_f. The goal is a model w^u that has "forgotten" D_f, keeps its utility on D_r and the test set D_t, and costs less than retraining (§2). The paper argues that what "forgetting" means depends on the application:

- **Removing biases (RB):** forget error should be as high as possible.
- **Resolving confusion (RC):** D_f holds the mislabelled examples. Success means the confusion between the two affected classes disappears, measured by IC-ERR and FGT-ERR (§5.3, §10).
- **User privacy (UP):** forget error should match a model retrained from scratch. Too high an error itself leaks membership. Success is measured with membership-inference attacks (MIAs) (§2, §5.4).

## 2. Main method

- **Distance (§3.1):** d(x; w^u) = KL( p(f(x; w^o)) ‖ p(f(x; w^u)) ). The frozen teacher (the original model) is the first argument and the student the second. The student starts as a copy of the teacher.
- **Objective (Eq. 3):** min over w^u of `(α/N_r) Σ_{D_r} d(x_r) + (γ/N_r) Σ_{D_r} CE(f(x_r), y_r) − (1/N_f) Σ_{D_f} d(x_f)`.
- **Optimisation (Alg. 1–3):** the objective is not optimised jointly, because doing so oscillates. Instead, epochs alternate:
  - a **max-epoch** does gradient ascent on mean d over D_f;
  - a **min-epoch** does descent on α·d + γ·CE over D_r.
  - Max-epochs run only for the first MAX-STEPS epochs; the remaining epochs are min-only.
  - The printed pseudocode never increments its loop counter. The official code runs `for epoch in 1..sgda_epochs: if epoch <= msteps: max; min`.
- **Hyperparameters (§9, Table 3):**
  - Table 3 sets the forget and retain batch sizes and the max/min step counts for each setting. Examples: CIFAR-10 ResNet class 2/3, selective 5/5.
  - Learning rate 5e-4, decayed ×0.1. Weight decay 0.1 at small scale and 5e-4 at large scale.
  - **The α and γ used per experiment are not reported.** Fig. 5 sweeps both over {0.1…3} and reports low sensitivity.
  - The official code uses α=0.001, γ=0.99 with SGD (large-scale notebook) and α=0.5, γ=1 with Adam (small-scale notebook). It also applies a KL temperature T (2–4) scaled by T², which the paper never mentions.
- **SCRUB+R (rewinding, §3.2):**
  1. Build a validation set D_v with the same distribution as D_f.
  2. Save a checkpoint every epoch.
  3. Set e* = Err(D_v) of the final model.
  4. Rewind to the checkpoint k = argmin_k |Err(D_f; w_k) − e*|.

## 3. Membership-inference evaluation (§5.4, §11)

- **Basic MIA (§11.1):**
  - Feature: per-example cross-entropy loss, clipped (to ±400 in the paper, ±100 in the code).
  - Data: forget examples are labelled 1. Test examples restricted to the same class(es) are labelled 0. The two groups are balanced.
  - Attacker: sklearn's default `LogisticRegression`, 5 stratified splits. The reported score is held-out accuracy, where 50% is ideal.
- **LiRA-for-unlearning (§11.2):**
  - 256 shadow models. For each, the attacker fits Gaussians to logit-scaled true-class confidence under "unlearned" vs "never seen" models.
  - Results are reported as ROC curves and AUC.
  - No LiRA code is released.
- **Effect of rewinding:** SCRUB pushes forget losses above test losses, which the attacker can exploit. On ResNet CIFAR-10 selective, the Basic MIA scores 78.00 for SCRUB, 58.67 for SCRUB+R and 54.00 for Retrain (Tables 2/23).

## 4. Experimental setup

- **Datasets:** CIFAR-10 and Lacuna-10, which is derived from VGG-Faces (face images).
- **Models:** ResNet-18 and All-CNN, pretrained on CIFAR-100 / Lacuna-100. No data augmentation. 3 seeds.
- **Forget sets:**
  - class forgetting (all of class 5);
  - selective forgetting (100 examples of class 5);
  - RC: mislabelled pairs between classes 0 and 1;
  - small-scale variants: CIFAR-5 / Lacuna-5.
- **Baselines:** Retrain, Original, Finetune, NegGrad+ (Eq. 4: β·CE_r − (1−β)·CE_f), Fisher, NTK, CF-k, EU-k, Bad-Teacher.
- **Metrics:**
  - Err (Eq. 5), IC-ERR (Eq. 6), FGT-ERR (Eq. 7; a raw count);
  - Basic MIA accuracy, LiRA AUC;
  - scale-up = runtime(Retrain) / runtime(method) (Table 6).

## 5. Authors' findings (quoted from the paper)

- **RB, ResNet CIFAR-10 class (Table 9):** SCRUB forget error 100.0, test error 15.73. Retrain: 100.0 / 14.72.
- **RB, selective (Table 11):** SCRUB forget error 70.33 vs Retrain 29.67. EU-k reaches only 23.7.
- **RC, CIFAR-5 ResNet (Table 1):** IC test error 19.0 for SCRUB, 24.0 for Retrain, 56.0 for Original.
- **UP, LiRA (Fig. 4):** AUC 0.92 for Original, 0.72–0.74 for SCRUB(+R), 0.79–0.80 for NegGrad+.
- **Speed (Table 6):** SCRUB scale-up is 5.33–7.84 on CIFAR-10. Fisher is slower than retraining (0.07–0.16).
- **Internal inconsistencies flagged by our reader:**
  - The All-CNN columns of Table 2 do not match Tables 21/22.
  - The Bad-T forget and retain values in Table 24 look swapped relative to Table 9.

## 6. Practical limitations

**(a) Stated by the authors (§6, §8, §11):**

- no theoretical guarantees;
- the min-max objective can oscillate (Fig. 6);
- rewinding cannot fix stopping too early;
- only modest datasets and models were tested;
- no settled definition of unlearning.

**(b) Our assessment:**

- **Stability:** the max-step objective is unbounded. Stability depends on few max-epochs, learning-rate decay and batch sizes tuned per setting.
- **α/γ:** the code's values fall outside the range swept in Fig. 5, so the sensitivity claim may not cover the settings actually used.
- **Rewinding with random forget sets:** rewinding needs a validation set with the same distribution as D_f. It is unclear what that would be for random forget sets.
- **Evaluation cost:** user-privacy evaluation still needs a retrained reference model.
- **Weak MIA:** the Basic MIA is weak and uses small samples, and the spreads are large (Table 4: ±28.99).
- **Memory:** teacher plus student roughly doubles memory.
- **Scope:** nothing is shown for Transformers or LLMs.
- **Personal data:** Lacuna is built from a face dataset. We should avoid it given the no-personal-data constraint.

## 8. Reusable, task-independent components

1. **Split builders:** class forget, selective forget (n random examples of class c), relabelled-confusion forget, and same-class validation subsets. Tests: disjointness, coverage, class counts.
2. **Error metrics:**
   - Err = 1 − accuracy (Eq. 5);
   - IC-ERR = (Σ_{k≠A} C_{A,k} + Σ_{k≠B} C_{B,k}) / (|D_A| + |D_B|) (Eq. 6);
   - FGT-ERR = C_{A,B} + C_{B,A} (Eq. 7).
3. **SCRUB losses (code form):**
   - `kl = F.kl_div(log_softmax(s/T), softmax(t/T), reduction='batchmean') * T**2`;
   - max loss = −kl;
   - min loss = α·kl + γ·CE.
4. **Schedule generator:** a pure function returning the per-epoch phase lists.
5. **Rewind selector:** argmin_k |fe_k − e*|, a pure function.
6. **Basic MIA:** clipped per-example losses → logistic regression → 5-split accuracy (add AUC and TPR@low-FPR).
7. **LiRA scorer:** φ = log(p_y / (1 − p_y)); score = log N(φ; μ_in, σ_in) − log N(φ; μ_out, σ_out).
8. **Reference-gap reporting:** |metric_method − metric_retrain|, and the scale-up factor.

Already in `src/euroai`: ROC-AUC, TPR@FPR, best-threshold accuracy (a loss-threshold MIA), bootstrap CIs, and seeded index splits.

## 9. Hackathon experiment ideas (ours, not the authors')

1. **CPU-scale reproduction.**
   - Setup: a small CNN on a CIFAR-5-style subset, forgetting 25 examples of class 0. Compare Finetune, NegGrad+, SCRUB and SCRUB+R over 3 seeds.
   - Baseline: Retrain.
   - Metrics: forget/retain/test error and Basic MIA.
   - Risk: MIA is noisy with tiny sets.
2. **Rewind target for random forget sets.**
   - Choose the checkpoint by the distance between forget-loss and held-out-loss distributions.
   - Baseline: SCRUB+R.
   - Risk: tuning against the evaluation attack itself.
3. **Hyperparameter audit (GPU, CIFAR-10/ResNet-18).**
   - Grid over α, γ, T, MAX-STEPS and forget batch size.
   - Baseline: the Table 3 settings.
   - Risk: needs a retrained reference per forget set and seed.
4. **LiRA-lite with 16–32 shadow models.**
   - Check whether the Basic MIA and LiRA rank methods the same way.
   - Metric: TPR@1%FPR.
   - Risk: compute, and noisy low-FPR estimates.
5. **Bounded max-step.**
   - Hinge or clip on the KL, to reduce oscillation.
   - Metric: variance of forget error across seeds.
